# pingtext

Ping CSV/TSV text tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/pingtext/

## Install / run

```bash
git clone https://github.com/theworker02/pingtext.git
cd pingtext
node src/cli.js
node --test
```
